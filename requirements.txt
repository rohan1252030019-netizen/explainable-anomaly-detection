# ============================================================
# Explainable Framework for Unsupervised Anomaly Detection
# Runtime dependencies — Python 3.10+
#
# Version ceilings are deliberate.
#
# This project broke twice because of unpinned majors: pandas 3.x removed
# behaviour the loader relies on, and NumPy 2.x turned `float()` on a
# one-element array from a deprecation into a TypeError, which a bare
# `except` in the explainability layer silently swallowed — every
# explanation quietly degraded to statistics-only.
#
# Upper bounds below mark the newest versions this code has actually been
# run against. Raise them deliberately, with the test suite as the gate:
#     python -m pytest
# ============================================================

# ── Core scientific computing ──────────────────────────────────────────────────
numpy>=1.26,<3
pandas>=2.0,<4
scipy>=1.10,<2

# ── Machine learning ───────────────────────────────────────────────────────────
scikit-learn>=1.4,<2
joblib>=1.3,<2

# ── Explainability ─────────────────────────────────────────────────────────────
# TreeExplainer on a scikit-learn IsolationForest explains the raw tree path
# length rather than score_samples; src/explainability/shap_explainer.py
# verifies additivity and falls back to the permutation explainer when the
# units disagree. 0.44+ is required for the Explainer API used there.
shap>=0.44,<1
